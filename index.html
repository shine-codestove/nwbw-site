모든 기능

🧭

실시간 방향 안내

다음 방향 전환점까지 거리와 방향을 직관적으로 표시. 나침반 화살표로 어느 방향으로 가야 할지 한눈에 확인. 경로 이탈 시 즉시 알림으로 빠른 복귀 가능.

📂

GPX 코스 지원

GPX 파일을 iPhone에서 가져와 Watch로 동기화. 인기 트레일 코스, 대회 코스를 그대로 따라 달리기. 고도 프로필로 업힐/다운힐 미리 파악. 러닝 완료 후 GPX Export 가능!

❤️

완벽한 운동 추적

심박수, 거리, 페이스, 칼로리 실시간 모니터링. 심박 존(Z1~Z5) 색상 표시로 강도를 한눈에. 1km 자동 랩에 더해 Apple Watch Ultra 동작 버튼으로 수동 랩 기록. 잡음을 걸러낸 정확한 누적 상승 고도. HealthKit에 운동 기록 자동 저장.

⌚

Apple Watch 최적화

독립 실행 - iPhone 없이 Watch만으로 러닝. 배터리 효율 최적화로 장거리 러닝 지원. Companion Mode - iPhone과 함께 사용 시 추가 배터리 절약.

📱

8가지 러닝 화면

구간 - 오르막·내리막·평지 구간별 남은 거리·상승·경사
CP - 다음 CP까지 거리, 도착 예상 시각, 컷오프 여유
1. 네비게이션 - 방향 나침반과 다음 포인트 거리
2. 지도 - 실시간 위치, 경로, 체크포인트 표시
3. 고도 - 전체 코스 고도 그래프 위 내 위치, 누적·남은·총 상승, 현재·최고 고도
4. 운동 통계 - 순정 운동 앱 스타일 큰 지표를 한 화면에, 심박 존 게이지
5. 랩 - 동작 버튼으로 기록한 바퀴별 랩 타임
6. 컨트롤 - 일시정지, 되돌아가기, 종료

🔥

Strava 연동

완료한 러닝 기록을 Strava에 바로 업로드. 경로, 고도, 실제 GPS 시각, 심박 데이터가 GPX 형식으로 전송되어 Strava에서 심박 그래프까지 볼 수 있습니다. 한 번 연결하면 토큰이 자동 갱신됩니다.

⛰️

클라임 안내

오르막 시작 200m 전에 길이·평균 경사·상승고도를 음성으로 안내. 실시간 경사도(%)와 상승 속도(VAM), 코스 기준 남은 상승고도까지 — 트레일의 언덕을 미리 알고 페이스를 배분하세요.

📈

구간 화면NEW

코스를 오르막·내리막·평지 구간으로 나눠 지금 구간의 남은 거리, 남은 상승, 평균·최대 경사와 다음 구간을 보여 줍니다. 대회에서 페이스를 나누는 기준이 됩니다.

📍

대회 CP · 컷오프NEW

iPhone 코스 상세 → 대회 CP에서 CP 이름·거리·보급 여부·컷오프를 등록하세요. Watch가 다음 CP까지 거리와 오르막, 도착 예상 시각, 컷오프 여유를 보여 주고 500m 전과 통과할 때 음성으로 알려줍니다. GPX 웨이포인트는 CP로 자동 인식합니다.

🪧

길안내 강도NEW

마킹이 좋은 대회는 '최소'로 이탈할 때만 한 번, 처음 가는 길은 '정밀'로 큰 갈림길까지 미리 안내받으세요. 설정 → 러닝 → 길안내 강도.

🔋

배터리 · 보급 알림NEW

배터리 20%·10%와 결승 전 배터리 부족을 미리 알리고, 10%에서 배터리 절약 GPS로 바꿉니다. 보급 알림을 켜면 정해 둔 간격마다 먹고 마실 시간을 알려 줍니다.

💾

러닝 기록 보존NEW

러닝 중 기록을 계속 저장합니다. 앱이 꺼져도 다시 열면 그대로 이어 달리고, 배터리가 꺼져 끝난 러닝도 저장할 수 있습니다.

🛟

안전 기능

되돌아가기 - 지나온 경로를 역방향으로 안내해 안전하게 복귀. 일몰 경고 - 예상 완주 시각이 일몰에 가까워지면 미리 음성으로 경고합니다. 네트워크 없이도 동작합니다.

🎯

스마트 러닝 보조

자동 일시정지 - 멈추면 자동으로 기록을 멈추고, 다시 달리면 재개. 목표 페이스 알림 - 목표보다 느려지면 음성으로 알려줍니다. 음성 알림 간격(거리/시간)도 자유롭게 설정.

🏁

랩 타임 & 동작 버튼

같은 코스를 여러 바퀴 돌 때 Apple Watch Ultra의 동작 버튼을 누르면 바퀴마다 랩이 기록됩니다. 러닝 전에 누르면 자유 러닝이 바로 시작되고, 랩 화면과 iPhone 기록 상세에서 바퀴별 시간·거리·페이스를 확인할 수 있습니다.

⚙️

설정 동기화

GPS 모드, 음성 알림, 목표 페이스, 화면 순서 등 iPhone에서 바꾼 설정이 Watch로 자동 동기화됩니다. Watch의 설정 화면에서 현재 적용된 값과 마지막 동기화 시각을 바로 확인하세요.

📡

라이브 트래킹

Watch로 달리는 동안 iPhone에서 실시간 위치와 운동 데이터를 확인. iPhone 앱을 열면 라이브 카드가 바로 나타나고, 연결이 끊겨도 데이터를 버퍼링했다가 자동으로 복구합니다. 러닝 기록은 iPhone에 없으면 워치에서 자동으로 다시 가져옵니다.
