NWBW의 주요 화면을 살펴보세요

iPhone Apple Watch
🧭

실시간 방향 안내

다음 방향 전환점까지 거리와 방향을 직관적으로 표시. 나침반 화살표로 어느 방향으로 가야 할지 한눈에 확인. 경로 이탈 시 즉시 알림으로 빠른 복귀 가능.

📂

GPX 코스 지원

GPX 파일을 iPhone에서 가져와 Watch로 동기화. 인기 트레일 코스, 대회 코스를 그대로 따라 달리기. 고도 프로필로 업힐/다운힐 미리 파악. 러닝 완료 후 GPX Export 가능!

❤️

완벽한 운동 추적

심박수, 거리, 페이스, 칼로리 실시간 모니터링. 심박 존(Z1~Z5) 색상 표시로 강도를 한눈에. 1km마다 자동 랩 기록, 누적 상승 고도 추적. HealthKit에 운동 기록 자동 저장.

⌚

Apple Watch 최적화

독립 실행 - iPhone 없이 Watch만으로 러닝. 배터리 효율 최적화로 장거리 러닝 지원. Companion Mode - iPhone과 함께 사용 시 추가 배터리 절약.

📱

5가지 러닝 화면

1. 네비게이션 - 방향 나침반과 다음 포인트 거리
2. 지도 - 실시간 위치, 경로, 체크포인트 표시
3. 고도 - 고도 프로필, 경사도·상승 속도, 남은 상승
4. 운동 통계 - 시간, 심박(존 색상), 페이스, 거리
5. 컨트롤 - 일시정지, 되돌아가기, 종료

🔥

Strava 연동

완료한 러닝 기록을 Strava에 바로 업로드. 경로, 고도, 시간 정보가 GPX 형식으로 전송됩니다. 한 번 연결하면 토큰이 자동 갱신되어 편리하게 사용할 수 있습니다.

⛰️

클라임 안내

오르막 시작 200m 전에 길이·평균 경사·상승고도를 음성으로 안내. 실시간 경사도(%)와 상승 속도(VAM), 코스 기준 남은 상승고도까지 — 트레일의 언덕을 미리 알고 페이스를 배분하세요.

📍

체크포인트·급수 안내

GPX 파일의 웨이포인트(CP, 급수 지점)를 자동 인식. 지도에 마커로 표시되고, 접근 200m 전 음성으로 알려줍니다. 대회 코스 GPX를 그대로 활용하세요.

🛟

안전 기능

되돌아가기 - 지나온 경로를 역방향으로 안내해 안전하게 복귀. 일몰 경고 - 예상 완주 시각이 일몰에 가까워지면 미리 음성으로 경고합니다. 네트워크 없이도 동작합니다.

🎯

스마트 러닝 보조

자동 일시정지 - 멈추면 자동으로 기록을 멈추고, 다시 달리면 재개. 목표 페이스 알림 - 목표보다 느려지면 음성으로 알려줍니다. 음성 알림 간격(거리/시간)도 자유롭게 설정.

📡

라이브 트래킹

Watch로 달리는 동안 iPhone에서 실시간 위치와 운동 데이터를 확인. 연결이 잠시 끊겨도 데이터를 버퍼링했다가 자동으로 복구합니다.
